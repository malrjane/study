# News Feed — Redux Saga

A React news feed application built with Redux Toolkit and Redux Saga.

## Features

- Automatically loads the first 5 news posts.
- Loads 5 more posts when clicking "Load More".
- Displays post dates, text, likes, comments, reposts, and views.
- Shows a loading spinner during requests.
- Automatically retries failed requests every 3 seconds.
- Hides the "Load More" button when no more posts are available.

## Tech Stack

- React
- Vite
- Redux Toolkit
- Redux Saga
- React Redux
