# Redux Saga Search

A simple React search application built with Redux Toolkit and Redux Saga.

## Features

- Search items by keyword
- Display matching results
- Show "Type something to search..." when the input is empty
- Clear results when the search field is empty
- Handle loading and error states
- Debounced search using Redux Saga

## Technologies

- React
- Vite
- Redux Toolkit
- Redux Saga
- React Redux
