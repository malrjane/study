# Movie Finder

A movie search application built with **React, TypeScript, and Redux Toolkit**, using the OMDb API.

## Features

- Search movies by title
- View movie details and IMDb ratings
- Add and remove movies from favorites
- Loading and error handling
- Navigation with React Router

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- Redux Thunk
- React Router
- Vite
- OMDb API

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
